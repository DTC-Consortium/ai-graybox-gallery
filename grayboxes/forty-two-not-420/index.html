Scenario

A literature review on a deadline

The situationYou’re a student research assistant in a biology lab. The lab is building an evidence table from 100 imaging papers: for each one, the sample size, the study design, and the sentence that supports them. A teammate fine-tuned a small model (with LoRA) on 600 hand-made extractions so it fills the table in a consistent format.
The report“BERTScore on the test set rose from 0.81 (prompted model) to 0.94 (fine-tuned). Ready to run on the remaining papers.”
What you noticeSpot-checking, you find paper 17 says “we retrospectively reviewed 42 de-identified scans.” The model wrote 420.
What you can and can’t seeYou have the model’s outputs, the papers, and the score. You didn’t build the training data or the test split.

The lab, papers, and numbers are fictional.

Flagged 0 rows.

Row 1 · Wrong number. 42, not 420. One extra digit barely changes the meaning score.

Row 3 · Invented values. The paper gives neither a size nor a design. The right answer is “not reported.” The model guessed, because its training data never showed “not reported.”

Row 5 · Wrong number, and an unsupported design. 120, not 1,200, and “crossover” isn’t stated: “both sessions” alone doesn’t establish it.

Row 2 is correct. 64 participants, randomized into two arms.

Row 4 is correct. 310 patients, retrospective.

Row 6 is correct. Nothing stated, so “not reported.” Rare for this model: see Task 3 for why.

Why the score missed it

Which check would catch each problem?

BERTScore compares meaning with a reference answer. It isn’t built to check facts.

Why this is a gray box problem

You can see the score, not how it was made

What you can see

The outputs · the papers · one summary number (0.94)

What you can’t see

Which papers were in training · how the test set was chosen · whether any training example said “not reported”

What the builder could check

The split list, by paper · per-field accuracy · how many errors were numbers

Gray box insight: one average score hides which fields fail and why. Ask for the evidence behind the number before you trust the number.

Key takeaway

Fluent is not the same as correct

A similarity score measures how close an answer sounds to the reference. It can’t tell 42 from 420. Choose the check that matches what matters: for numbers, exact match against the source.
