Building the Northstar Workshop Assistant

One agent · one approved tool · evidence you can check

What it shows

A student asks whether a research workshop has room on Thursday. The handbook can say how to request a seat; only the live schedule can say whether one is open.

The video builds a single bounded agent with one read-only lookup tool and runs the Week 10 tests. It then adds a protected mock action that runs only with a coordinator's approval code, breaks the tool on purpose, repairs one line of the prompt, and retests the same request. It ends on the activity record: the denied status and submitted = false prove the safeguard worked, not the assistant's sentence.

An answer is not an action. Trust what the record shows.
