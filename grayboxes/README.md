# Hosted gray boxes

Prebuilt single-file HTML decks that the gallery hosts itself. Each folder is
one gray box, served at

    https://dtc-consortium.github.io/ai-graybox-gallery/grayboxes/<slug>/

Every `index.html` here is the author's file, committed unmodified. To add
one, see "Already have the deck as an HTML file?" in
[`CONTRIBUTING.md`](../CONTRIBUTING.md).
